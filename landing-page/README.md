# 🟡 AgentDock — Yellow Landing Page

A simple yellow-themed landing page with a form application, floating animations, and smooth transitions.

## Files

- `index.html` — Full landing page (HTML + CSS + JS in one file)
- `serve-landing.js` — Tiny Bun server to preview locally

## Preview

```bash
bun run landing-page/serve-landing.js
```

Then open **http://localhost:3434** in your browser.

## What's included

- 🟡 Yellow color palette (warm, cheerful theme)
- 🎈 Floating animated shapes in the background
- 📝 Animated application form with validation
- ✨ Scroll-triggered feature cards
- 🔔 Toast notification on submit
- 📱 Responsive (mobile-friendly)
- 🖱️ Smooth hover effects & transitions
